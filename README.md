This repository contains independent machine learning projects undertaken as part of my self-learning and practical exploration of machine learning methods.

The projects focus on applying concepts learned through coursework and independent study to real datasets, with an emphasis on real-world problems for understanding the complete machine learning workflow—from data exploration and feature engineering to model selection, validation, interpretability, and evaluation.

Each project is organized in its own directory, containing notebooks, results, and a project-specific README that describes the problem, methodology, and main findings.
